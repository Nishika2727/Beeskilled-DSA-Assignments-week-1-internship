# Data Structures & Algorithms Internship - BeeSkilled Campus

This repository contains C++ implementations for the Data Structures and Algorithms assignment tasks and mini-project assigned by BeeSkilled Campus.

---

## 📌 Repository Structure

| File / Section | Program Name | Description |
|---|---|---|
| `01_linear_search.cpp` | Linear Search | Searches for a target value sequentially in an unsorted array ($O(N)$ time complexity). |
| `02_binary_search.cpp` | Binary Search | Efficiently finds a target value in a sorted array using divide-and-conquer ($O(\log N)$ time complexity). |
| `03_bubble_sort.cpp` | Bubble Sort | Sorts an array in ascending order while keeping track of total swap operations. |
| `04_reverse_array.cpp` | In-Place Reversal | Reverses an array without using any additional memory allocation ($O(1)$ auxiliary space). |
| `05_student_marks_analyzer.cpp` | Student Marks Analyzer | **Mini Project:** Takes input of student marks, processes them, sorts the scores, and displays the top 3 highest scores alongside the class average. |

---
